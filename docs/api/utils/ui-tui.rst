UI - terminal client
====================

The ``cli`` subcommand's terminal client is a lightweight REPL for quick
testing.  The full Textual terminal TUI is the ``tui`` subcommand (see
:doc:`../../components/tui`); both share the ``klea_utils.ui`` helpers.

UI - terminal client¶

The cli subcommand’s terminal client is a lightweight REPL for quick testing. The full Textual terminal TUI is the tui subcommand (see Terminal interface); both share the klea_utils.ui helpers (UI — NiceGUI).

The Textual application¶

Shared Textual terminal client.

The Klea TUI is an in-process Textual app that consumes the backend’s /query/stream SSE endpoint, one active session at a time (ADR-0050, devdocs/system/tui.md). This module holds the shared App/Screen, the two-panel layout, and the single run worker that feeds the shared stream reducer. App-specific composition enters through klea_utils.ui.tui.context.TuiContext.

Streaming currently renders progress (the turn-status line) and complete (the final message); richer rendering, turn-status states, HITL and session management land in later steps.

Components¶

Session-command handling for the TUI frontend (ADR-0047).

The TUI owns its client-side commands and merges them with the server catalogue fetched from GET /commands. An input beginning with / is validated against the merge: a client command runs locally and its output is rendered as a system transcript message; a server command is forwarded as the query (the graph’s command node runs it); an unknown command is rejected locally and never sent. A leading // escapes a literal slash.

Capabilities start empty (devdocs/system/tui.md): the TUI has no browser file picker, and local-filesystem/shell capabilities are deferred with the session-workspace work.

HITL review/input/permission panels for the Klea TUI (ADR-0046).

When a run pauses at an interrupt, the app mounts an inline panel in the chat panel rather than a modal, so the transcript stays scrollable while the user reads the ask and decides. A review ask offers Approve / Request changes / Cancel; an input ask offers one field per question plus Answer / Cancel; a permission ask offers once/session/not-a-path/deny per requested path (ADR-0007).

Each panel posts HitlDecisionPanel.Decided (carrying a HitlDecision) instead of dismissing; the app removes the panel and resumes the same run.

Query input widget for the Klea TUI.

The chat panel’s query entry: a multi-line, soft-wrapping text area that grows with its content up to a capped height (then scrolls), mirroring the web client’s autogrowing textarea. The entry sits at the bottom of a themed frame (so the cursor is on the bottom line and the box grows upward, like the web composer). Enter submits the query; Ctrl+J (Textual’s newline key) or Shift+Enter inserts a newline, so a pasted multi-line block can be edited before sending. Ctrl+J is the portable choice: it is a distinct key (\x0a) sent by every terminal, whereas Shift+Enter is only distinguishable on terminals that implement the extended (Kitty) keyboard protocol.

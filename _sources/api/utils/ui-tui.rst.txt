UI - terminal client
====================

The Textual terminal TUI is the ``tui`` subcommand (see
:doc:`../../components/tui`); it shares the ``klea_utils.ui`` helpers
(:doc:`ui-nicegui`).  Bare ``klea`` / ``klea-rag`` also launches it.

- `retriever.retrieve(...)` and `cross_encoder_rerank` run via

  serialise.

  `RetrieveInfoNode`; fails fast on missing dep/model. One-time ~91 MB
  Hugging Face download, cached on disk.
- Removed the module-global cache + double-checked lock: with single ownership
  there is no shared mutable state to guard.

## Errors and Lessons

- **`asyncio.to_thread` is not serialisation.** It dispatches to a thread pool,
  so concurrent callers really do run in parallel. It cannot replace a lock
  guarding a hidden cache - only removing the shared cache (dependency
  injection) does.
- **A hidden module-global cache must be locked by the library**, not the
  caller (the caller cannot reach it). For a resource the app owns, prefer
  single ownership + injection over a locked global.
- **Local model inference is inherently blocking.** `to_thread` is the
  pragmatic answer; a dedicated inference server (TEI/Infinity/Triton) with an
  async client is the scale answer, not needed now.
- **ruff B010** rewrites `setattr(obj, "const", v)` to `obj.const = v`, which
  then trips `ty` on `ModuleType`; faking `builtins.__import__` in the test
  avoided both.
- **Pre-existing `ty` diagnostic** in `rag_pkg/tests/test_retrieve_info.py`
  (`node.write_custom_stream = lambda ...`, also in `test_route_evaluator.py`)
  left untouched as out of scope.

## Objective

labels, a wrapping button-driven feedback field in the terminal, and
height-bounded, spaced ask bodies.

  reads `Feedback (required to revise)`.
- `QueryTextArea` gained `submit_on_enter` and `placeholder`; the TUI feedback

  spaced body.

## Errors and Lessons

  wiring, so the guard had to key off the `query-input` id rather than assume
  only one text area exists.
- Letting the feedback field keep Enter-to-submit posted stray queries; making
  the button the sole submit path keeps the ask state intact.

## Errors and Lessons
- CPython asyncio `StreamReader.readline()` raises `LimitOverrunError` (`ValueError: Separator is not found, and chunk exceed the limit`) when no newline appears within the 64 KiB frame limit; rotated JSON logs contain such lines, so any tool emitting a newline-free frame above the limit failed wholesale rather than degrading.
- The `grep` hunk budget (100,000 chars) exceeded that limit on its own, so the cap had to be lowered as well as the individual lines capped.
- `read_file` truncation uses a variant marker (`... [line truncated: exceeds N chars]`) because the number of dropped characters is unknowable when only the head is kept.

## Errors and Lessons

- **Provenance is structural.**  A user-invoked command's output must not be
  injected as a `CallToolResult` (that frames it as the assistant's own tool
  call).  Use the user channel (`HumanMessage`) with an explicit label.
- "User-invoked" is not the same as "LLM-free" -- commands are defined by
  *who invokes them*; some are pure state changes, others call a model.
- Scope-tag tests drift: adding a tool that shares an existing scope tag
  (`web`) silently changes what an `include_tags` filter exposes.

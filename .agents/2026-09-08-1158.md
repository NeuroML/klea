## Errors and Lessons

- LSP diagnostics in this repo are stale/noisy (e.g. `base.py:254/369`,
  `inspector.py:94`, `test_mode_router.py:51` "after decorator"). Trust
  `ty check` (36 pre-existing baseline) + pytest instead. Verify with the
  CLI, not the LSP.
- `edit` tool matched an indented `ui.tooltip` line without error during a
  status_pane slot insertion -- always re-read the section after editing.
- `edit` can silently drop/swap adjacent lines when old/new strings are
  near-identical (lost a whole import block in `test_chat_api.py`;
  `stream_response` indentation) -- re-read + `git diff HEAD` before
  presenting.
- Full-suite pytest runs dirty `vector_stores/*/chroma.sqlite3` binaries;
  `git restore` them after tests.
- `aget_tuple(config) -> CheckpointTuple | None` (langgraph 1.2.11) is the
  way to detect "thread never ran" vs projecting state-schema defaults.
- LangGraph `_coerce_context` only validates a **dict** against
  `context_schema`; passing a model instance bypasses validation.
- `mask_sensitive` was top-level-only originally: nested keys (e.g.
  `model_overrides.chat.api_key`) leaked until it was made recursive --
  when adding log lines for nested payloads, sanitize the whole shape.
- Raising/stashing gotcha: a `git stash push`/`pop` (for a `ty` baseline)
  left `base.py` staged -- stage index is not restored cleanly without
  `--index`; check `git status` afterwards.
- `uv run` in `utils_pkg` created a stray `.venv` + `uv.lock` -- use the
  existing venv (`/home/asinha/.local/share/virtualenvs/klea-3.13`) or
  clean up after.

## Notes

- Node-scoped stream types (`info`/`debug`/`state`/`usage`) require
  `node`; `context` is graph-level with no `node`.
- `graph.update_state()` emits no stream events, so mode changes ride the
  next query.
- Hydration decision: mode stays in checkpointed graph state (single
  source of truth, ADR-0032); nothing copied into the sessions db -- an
  unsent query is not a chat yet. After a reload, `requested` is restored
  from the checkpoint; an empty `query_extra` would otherwise send the
  server default and silently reset the whole-object `Mode` field.
- `POST /query` deliberately returns no context (bare `ainvoke`, no
  `values` events); callers use `/query/stream` or the context GET --
  rationale noted in the `run_graph_invoke` / `run_query` docstrings.
- Session offset: PR 4-7 built on the earlier session log
  `.agents/2026-09-02-1629.md` (utils/apps split, ADR-0031).

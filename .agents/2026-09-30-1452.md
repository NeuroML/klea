### LLM retry reporting

- Folded `progress` into the typed stream contract: `NodeStreamEvent.type`
  gained `"progress"`, its display line lives in `data.heading`, and `node`
  stays the stable identity the runner keys timing/dedup on.  A same-node
  heading change (a retry) is forwarded without resetting the node timer.
  `NodeStreamData.summary` now defaults to `""`; all progress emitters use
  the new `AbstractLangGraphNode._emit_progress()` helper.
- `BaseLLMNode._emit_retry` reports each LLM invoke retry (context overflow,
  truncation, empty, empty structured, transient timeout) as a progress
  heading (`<label> (retry n/m: <reason>)`) plus an inspect entry
  (`heading="Retry"`, structured `details`); warning logs are unchanged.
- Web (`stream.py`) and TUI (`repl.py`) render `data.heading`.
- Tests: emit events at the node level (`test_llm_invoke_retries.py`) and,
  new, end-to-end through a real compiled graph
  (`test_graph_base.py::TestRetryEventsStreamed`), plus progress handling in
  `TestProgressStreaming`/`test_stream_events.py`.
- No in-app fault-injection hook yet, so the retries are hard to force by
  hand (only truncation is reachable via a tiny `providers` token cap); a
  debug-gated `KLEA_FAULT_INJECT` is proposed for a later item.

## Errors and Lessons

- `ChatHuggingFace.from_model_id` defaults to `backend="pipeline"` (local
  download); with no third segment the picker always hit that default.  The
  real bug was the UI not exposing the third segment, not the catalogue getter.
- HF routing policies (`cheapest`/`fastest`/`preferred`) must be appended to
  the model id; `InferenceClient(provider=...)` accepts only `auto` or a
  concrete provider name.
- models.dev's `huggingface` provider lists only 78 curated (mostly large)
  models; small models (SmolLM2-135M/360M, Qwen2.5-0.5B, ...) are not present
  and must be typed (free text).  models.dev model entries do carry
  `reasoning_options` (the source opencode uses for variants).
- Tooltip clipping came from the global `.q-tooltip { white-space: nowrap }`;
  wrapping fixes it app-wide.
- The local HF smoke test is blocked by a broken `torch` in the maintainer's
  env (`undefined symbol: ncclCommResume`); 8 ingestion/worker tests fail for
  the same reason (unrelated to this work).
- NiceGUI's `ui.run(favicon=...)` accepts a local file (served via a
  `/favicon.ico` route), an `http(s)`/`data:` URL, raw SVG, or a single
  character.  The web app subprocess runs from its own package directory, so
  a relative `--favicon` path must be resolved to absolute in the parent CLI.
- `klea_utils` ships non-Python assets via `include_package_data = True` +
  `MANIFEST.in` (already used for `nodes/prompts`); the bundled favicon uses
  the same mechanism.
- `write_custom_stream` calls `get_stream_writer()`, which raises
  `RuntimeError` outside a LangGraph run.  Retry reporting runs inside
  `_invoke_with_retries`, which unit tests call directly, so `_emit_retry`
  guards the emission (the warning logs still fire).
- The runner deduped `progress` on `node` (which *is* the label) and dropped
  `data`; extending it to forward `data` and also yield on a heading change
  gives retries a live line without a new event type.

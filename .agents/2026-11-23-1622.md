## Objective
Fix the `klea-eval` execution-check path so eval cases run and grade in the staged per-case workspace, and make the bundled hello-world sample suite work out of the box.

## Completed
- Fixed the per-case working directory: eval requests now send the staged per-case workspace as `client_context.cwd`, so tool and file cases no longer run in the eval process's own directory and an execution-check case grades the files the agent actually produced.
- Relocated the hello-world sample suite's case fixtures under the run's `workspace/` so the sample runs out of the box.
- Corrected the exit-code contract: a recorded failing eval grade now exits 1, while exit 4 stays reserved for a declared expectation that recorded no grade.
- Verified the bundled hello-world suite passes live end to end.

## Errors and Lessons
- The execution-check failure traced back to the case running in the eval process directory rather than the staged workspace; the agent's output was therefore never where the grader looked. Sending `client_context.cwd` is the single point that keeps producer and grader aligned.
- Exit codes had conflated a failing grade with a missing grade; keeping exit 1 for a recorded failure and exit 4 only for a declared expectation with no grade keeps CI scripts unambiguous.

**Authoring agent:** opencode

### Decision closures

Three decision closures were agreed in this session and recorded in the `devdocs/` commit made at step 8:

- No harness-level sandbox or permission model: the eval harness does not police what a case may do; containment is a deployment concern, not a harness feature.
- Per-benchmark converter script: each benchmark gets a converter that emits case JSONL plus fixtures, instead of a general adapter contract, because a converter is cheaper than a permanent adapter surface.
- Repository/container binding is out of scope: deciding which repository or container a case runs in is provisioning, not a correctness statement.

Two carve-outs qualify these closures:

- The process-group kill stays a backlog item.
- A case command inherits the harness environment, so a suite author must be trusted.

Container isolation plus trusted suite authors is the accepted boundary; a converter is cheaper than a permanent adapter surface.

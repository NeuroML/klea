## Design decisions
- Review info is LLM-synthesized over recorded `step_outputs`, so it covers
  arbitrary/third-party MCP tools -- not a deterministic diff extractor.
- Evidence gathering is Planner-planned tool steps, not an agentic review node.
- Generation stays separate from judgement: `ReviewProgress` synthesizes, the
  Evaluator judges + checks readiness, `AwaitHuman` stays non-LLM.
- Whole-plan approval (Planner) and checkpoint (Evaluator) both converge on
  `ReviewProgress`; the Planner->review edge was not removed.

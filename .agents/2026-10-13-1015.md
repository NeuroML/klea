## Completed

- **`/sessions` (web client command)**: list (pinned first, 1-based index,
  active/pinned markers), `switch <n|id>`, and `delete <n|id>` with a
  confirmation dialog.  The sidebar's per-chat delete now routes through the
  same confirmation (previously unconfirmed).  `/help <command>` and the
  session list render as Markdown.
- **Graph command hand-off (ADR-0047 framework)**: a graph command handler may
  be `async`, and may hand off to another node.  `GraphCommandResult.route` ->
  transient `command_route` state field -> `command_route_router` -> a
  conditional edge after the command node (`""` = `END`).  Chose
  conditional edges over LangGraph `Command(goto=...)` (the latter's
  dynamic-target benefit does not apply; static topology + no extra
  super-step); documented in `system/graph-routing.md`.
- **`/compact`**: a dedicated `Compacting memory` `SummariseMemoryNode`
  instance (threshold `0`, memory-gated) as the hand-off target.  The
  summarise node now always reports its outcome to the **inspect pane**
  (summarised / nothing new / no usable summary) and never writes the chat
  unless given an `announce` message (the manual-compaction confirmation).
- **Memory window tunable**: new agent config `general.memory`
  (`summarisation_threshold_chars` default `40000`, `num_history_chars` default
  `20000`; previously hardcoded `10000`/`10000`).
- **`/init` (cheap first cut)**: hands off *back into the normal path* with a
  synthesised prompt (`route="init"` -> `Determining mode`), so the ordinary
  planner/tool loop explores the project and writes `AGENTS.md`.  A
  full-fledged dedicated init node is deferred (backlog).
- **`/commands` dropped**: redundant with bare `/help`.
- **Docs synced**: user docs (`components/commands.rst`, `components/agent.rst`),

## Errors and Lessons

- NiceGUI user simulation: the chat-list three-dot menus are Quasar `QMenu`
  popups; the simulation's `only_visible` filter treats them as hidden, so
  their items are unreachable in tier-1 tests (the sidebar delete could not be
  UI-tested; the command path was).
- LangGraph: a node returning `Command(goto=...)` overrides its static edge,
  and `add_edge(node, END)` writes no runtime branch channel (`END` is
  implicit) -- so a plain dict return ends the run and a `Command`/route
  hand-off works cleanly.
- `dict[str, str]` is not assignable to `add_conditional_edges`'s
  `dict[Hashable, str]` (dict key invariance); annotate the path map as
  `dict[Any, str]`.
- Ruff does not reindent docstrings: an edit that matched the module docstring
  with class-style indentation broke it; re-check docstring indentation after
  edits.

## Completed

- Docs build: `graph/base.py` used `Client | None` at class-definition time.
  Sphinx mocks `fastmcp`/`mcp` for autodoc, so this evaluated to
  `_MockObject | None`, raising `TypeError` and cascading into 11 warnings
  that failed `sphinx-build -W`. Added `from __future__ import annotations`
  to defer annotation evaluation (`2b078c4a`).
- macOS start time: `/proc/<pid>/stat` does not exist, so the owner record
  stored `starttime: null`. Added a `ps -o lstart=` fallback (C locale, UTC)
  while keeping the Linux `/proc` fast path (`7bcd2534`).
- Windows lockfile: `msvcrt.locking` at offset 0 denied reads of the JSON
  payload, causing `PermissionError` in tests and an empty owner record in
  the stale-lock check. Lock one byte at a 1 MiB offset instead (`3c2f8748`).

## Errors and Lessons

- Sphinx `autodoc_mock_imports` only intercepts modules not already imported;
  import order can hide failures locally that CI hits. Mocked modules cannot
  satisfy runtime `X | None` annotations.
- Windows byte-range locks are mandatory: locking byte zero makes the whole
  small owner record unreadable by any handle, including the same process.

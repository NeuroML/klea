# Session: 2026-09-29-1047

**Authoring agent:** opencode
**Model:** deepseek-v4.1-flash

## Objective

Fix a batch of NiceGUI model-selection flow bugs (stale setup prompt, stale
credential labels, delete-session state, save-all-roles), improve how the
inspector renders streamed `details`, make the agent's JSON config optional,
gate the graph-diagram export on debug, tighten the agent planner prompt, and
rework the task-path loop budgets.  Also investigate why the agent web client's
NiceGUI data lands under `klea-web`.

## Completed

- Chat welcome CTA / status pane refresh after models or API keys change
  (`_refresh_scope` now calls `ctx.render_chat_area()`).
- Model dialog is a `@ui.refreshable` body; credential labels rebuild after a
  key is saved/cleared.
- Delete user session clears and re-fetches `session_model_info` (and
  credentials) for the new identity, so the setup prompt reappears; send state
  is refreshed in both delete paths.
- "No API key required" only for keyless providers (e.g. Ollama); unset model
  shows "No model selected", bare model shows "No API key configured".
- Credential label updates live as a model is typed; "Manage API keys"
  recognises unsaved typed models (client-side provider/requires_key).
- Single bottom Save persists all changed roles; per-tab Reset stays in the
  dialog (does not close).
- Backlog: NiceGUI element-rendering test harness item.
- Inspector details are now readable: shared `format_details`
  (`klea_utils/ui/inspect_format.py`) keeps the JSON shape, expands multi-line
  string values (prompts) at their original column, and inlines JSON-encoded
  string values.  It delegates structure/escaping to `json.dumps` via a
  newline sentinel.
- New `inspector_code.py` renders those details with a code box, Pygments
  JSON highlighting and a copy button, bypassing `ui.code` (which renders
  through a markdown2 fenced block and breaks on code fences in the content).
- Tests: `test_inspect_format.py`, `test_inspect_code.py`.
- Agent JSON config is now optional: `config_file_default = ""` for
  `KleaAgent`, and `BaseLangGraph._load_env` starts from `config_class`
  defaults when no config file is selected.  RAG keeps its required
  `klea_rag.json`.  No profile now means no config file, not a default one.
- Graph diagram export (`*-lang-graph.png` + `.mmd`) is debug-gated:
  `_export_graph_png` runs only under `--debug`/`KLEA_LOG_LEVEL=debug`
  (still skipped in Docker), so normal runs skip the Mermaid network call
  and the stray artifacts.
- Planner prompt: `reasoning` steps are now explicitly not for evaluation
  (the Evaluator judges criteria) nor for the final answer (the answer-composer
  synthesises it); a reasoning step must be consumed by a later step.  Then
  consolidated the prompt (145 -> 91 lines) by merging the Deciding/Review
  sections and removing duplicated status/reason/goal text.
- Removed `tool_rounds`: the per-step (`tool_retry_counts`, `step_attempt_counts`)
  plus replan (`automated_plan_revisions`) budgets already guarantee
  termination, and the hardcoded 8-round cap false-aborted long/deep or
  multi-replan runs.  Replaced with a fail-closed plan-size guard
  (`Planner.max_plan_steps = 30`: validated, then `unplannable` if the model
  still exceeds it), bounding the only unbounded input.
- `TriageRouter.max_retries` raised 2 -> 3 (three re-picks per step).

## Errors and Lessons

- `provider_requires_api_key("")` is `False`, so "unset" and "keyless" are
  indistinguishable via `requires_key` alone; the UI must check provider/model
  emptiness explicitly.
- NiceGUI `ui.tabs(value=...)` is typed `Tab | TabPanel | None`; set `.value`
  after creating the tab children to avoid the `ty` error.
- `@ui.refreshable`'s `.refresh()` returns `AwaitableResponse`, not `None`; a
  callback that invokes it must be typed `Callable[[], Awaitable[None]]`.
- `ui.code` is a `ui.markdown` plus a fenced block: content containing a code
  fence closes it early.  Do not use it for arbitrary content.
- Pygments' stock `JsonLexer` already tolerates real newlines inside strings
  and colours keys `Name.Tag`; an early custom lexer tagged every string the
  same and lost the key colour (reverted to the stock lexer).
- `--profile` was already optional; the actual blocker for running the agent
  with no profile was the mandatory default JSON config (`klea_agent.json`)
  in `_load_env`.  The fix is an empty agent default, not a CLI change.
- The task-path loop already terminates via per-step and replan budgets, so a
  global round cap (`tool_rounds`) was redundant *and* harmful (arbitrary
  value, ignores batching, not reset on replan).  Bound the plan length
  instead, which is the only model-chosen unbounded dimension.
- The planner kept adding terminal "synthesis/verdict" reasoning steps until
  the prompt explicitly said the answer-composer does the final synthesis and
  that the reply is not a valid consumer of a reasoning step.

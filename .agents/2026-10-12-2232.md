## Errors and Lessons

- **Non-editable installs need package data.** Prompt `.md` files must be in
  `MANIFEST.in` / `package_data`; `include_package_data = True` alone is not
  enough without a MANIFEST. `_load_prompt_file` resolves the prompts dir
  relative to the **installed** subclass file, so a source-only prompt (editable
  install) hides this.
- NiceGUI user simulation: `UserInteraction.type()` **appends** (does not
  replace), and `should_not_see`/`should_see` also match an input's own value --
  assert on the suggestion list, not on the raw text substring.
- `ui.download.content(...)` works in the NiceGUI simulation (the `/export`
  download hook is exercised end-to-end in tests).
- A full `pytest` run rewrites the tracked `vector_stores/nml-elife/*`
  fixtures -- restore them afterwards (never commit).
- Inline LSP diagnostics are stale after cross-file edits in this environment;
  trust `ruff` / `ty` / `pytest`.

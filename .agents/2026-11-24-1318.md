## Follow-up: whole-tree kill deferral accepted

The process-group kill / whole-tree kill question for case commands is now
recorded as an accepted, deferred limitation -- not an open backlog defect --
matching the existing `run_command` entry.  This supersedes the earlier
"Remaining open items" bullet above that still called it an open backlog
defect: `subprocess.run`'s timeout kills only the direct child, a portable
whole-tree kill is not implemented (it would need a platform-specific mechanism
or a racy recursive walk), and the timeout is still reported, so the run never
depends on the surviving descendant.  Recorded in `devdocs/backlog.md` (both
entries), the new "Case command descendants" bullet in
`devdocs/system/agent-evaluation-harness.md`, and ADR-0062.  No code change and
no CHANGELOG bullet (no user-visible behaviour change; `klea_eval` is not
published).

## Errors and Lessons

- The seed-0 attempt of the live run failed transiently: the stream aborted and
the retry hit HTTP 409 "This chat is awaiting your answer." The backend
single-flight/HITL guard rejects a same-thread retry while a run is still
active, so a stream abort can surface as a 409 rather than a clean failure.
Re-running with `--harness-seed 1` (a fresh chat identity) completed normally.
- A 409 from the streaming endpoint is a pre-stream rejection, not a turn
result, so it reaches the runner as an endpoint error rather than a scored
turn; a fresh identity is the reliable recovery path today.

## Completed
- Per-chat delete purges the checkpoint (`13dd5536`): `api/sessions.py`
  `delete_chat` cancels the chat's active run, then
  `checkpointer.adelete_thread(thread_id_for(...))`, then `store.delete_chat`;
  `delete_user` reuses `thread_id_for`. Tests in `test_api_routers.py`
  (`TestSessionsDelete`).
- Web `--resume <chat_id>` / `--continue` (`0948e8dd`): `resolve_initial_chat`
  in the NiceGUI bootstrap, threaded CLI -> `_run_web` -> `app.py` parser ->
  `run_*_web` -> `run_nicegui_server`; `--continue` opens the most recently
  updated chat.
- Web open + exit (`6e9fa2b2`): `ui.run(show=open_browser)` uses NiceGUI's
  portable browser opener (waits for the port, maps `0.0.0.0` -> `127.0.0.1`);
  new `--open/--no-open`. New `/exit` client command + `PageContext.exit_app`
  hook + `stream.stop_all_streams`; the header power button always confirms,
  `/exit` is immediate; exit best-effort `window.close()`, then a short-delayed
  `app.shutdown()`.
- TUI `/exit` (`210c37f7`): `EXIT_APP_SERVICE`; `_exit_after_stop` stops the
  active run (`action_stop`) then `self.exit()`; the command is
  `while_streaming=allow`.
- Docs/changelog/backlog (`42c49325`, `3861f7cf`, `31f5636f`): project-root

## Errors and Lessons
- `ty` reports stale/noise diagnostics: `klea_utils.ui.client has no member
  <fetcher>` and unresolved `textual` imports are pre-existing; new handlers
  referenced before their definition also show as transient "undefined name".
  Filter with `ty check | rg -v "<known noise>"` rather than trusting the LSP.
- NiceGUI `app.shutdown()` only stops the server process; the browser tab
  stays open. `window.close()` is blocked for user-opened tabs, so it is
  best-effort only.
- `ui.run_javascript` needs a live client context: fire it in the event
  handler, then schedule the shutdown in a detached background task after a
  short grace.

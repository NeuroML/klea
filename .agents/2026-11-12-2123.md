# 2026-11-12-2123

**Authoring agent:** opencode
**Model:** opencode-go:deepseek-v4.1-flash

## Summary

Reject unknown model-override roles instead of silently storing them. The models
router now validates the role on write and returns 422 naming the supported
roles, so typos no longer create undead overrides.

## Changes

- Unknown roles are rejected with 422 on override set, and on delete when no
  stored override exists; the error message names the supported roles.
- The DELETE escape hatch is kept: a stale stored override for a role that is no
  longer declared can still be cleared.
- `_resolve_active` no longer resurrects undeclared stored roles, so the active
  model config only reflects roles the graph actually declares.
- Tests added covering the rejection path and the stale-row delete path.
- ADR 0014 and CHANGELOG updated.

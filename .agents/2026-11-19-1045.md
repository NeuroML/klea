## Scope

Eval harness cost and bias reporting: replace the raw `cost` metric with a
provider- and time-independent normalised token accounting, and keep
`cost_estimate` as a non-gating informational field.

## Decisions

- Reject `cost` as a scored metric. Cost is provider- and time-dependent, so it
  cannot be compared across runs and must not influence pass/fail.
- Score on normalised token units instead of raw counts. Each unit is defined
  as: fresh (uncached) input tokens weigh 1; cached input tokens weigh 0.1 and
  substitute for their corresponding input token rather than being counted in
  addition; output tokens carry their own separate, tunable weight. The output
  weight stays a single knob and is not folded into the input scale.
- Derive the normalised units on read from the existing token fields, so no
  schema bump is required and previously written results stay readable.
- Keep `cost_estimate` as an informational passthrough: it is recorded and
  displayed but never gates or weights a score.
- No bundled price table. Any cost figure is supplied by the caller or the
  provider; the harness does not embed rates that would silently age.

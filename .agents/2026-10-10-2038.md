# Session: 2026-10-10-2038

**Authoring agent:** opencode
**Model:** opencode-go/deepseek-v4.1-flash

## Objective
Implement a bundled `web_search` tool for the research agent, mirroring the
DOI resolver's multi-provider fallback design, and document/fix related drift.

## Completed
- Designed and implemented `web_search` as a bundled MCP tool: a
  keyless-first provider pool (Tavily, Exa, Parallel, Firecrawl hosted MCP
  endpoints, no key required) with sequential fallback, plus keyed opt-in
  (Brave, Serper; and keyed mode for the four when their env key is present).
- New package `utils_pkg/klea_utils/mcp/tool_impls/search/`: `base.py`
  (`SearchResult`/`SearchProvider`/`SearchSession` + `SERVICE_ORDER`/
  `KEYED_SERVICE_ORDER`), `errors.py`, `transport.py` (hosted MCP JSON-RPC
  `_mcp_call`, REST helpers, honest `klea-web-search/<version>` User-Agent),
  `hosted.py` (`_HostedMCPProvider` + result-normalisation helpers),
  per-provider modules (`tavily`, `exa`, `parallel`, `firecrawl`, `brave`,
  `serper`), and `resolver.py` (`WebSearchResolver`: priority order +
  fallback; keyed providers appended when available).
- Thin framework-agnostic impl `tool_impls/web_search.py` and a wrapper in
  `mcp/server/bundled_tools.py` (tags `{bundled, web, search}`, read-only +
  open-world annotations). Tests in `test_web_search.py` /
  `test_bundled_server.py` pass (59 in the bundled-server suite).
- ADR `devdocs/adr/0048-web-search-providers.md` (renumbered from 0047, which
  is reserved for the commands ADR in another worktree).
- Docs: `install.rst` provider keys + env-file caveat; `mcp-servers.rst`
  `search` tag + tool description; `mcp-permissions.md` network note; fixed
  stale web-search claims in `Readme.md`/`docs/index.rst` and a stale
  `mcp_pkg/AGENTS.md` tree line; CHANGELOG entry; backlog deferral.
- DoiResolver fix: honest `klea-ingest/<version>` User-Agent, and corrected
  ADR-0027 drift (no tenacity backoff; own synchronous `httpx.Client`;
  `mailto` is a query parameter, not a UA header).

## Errors and Lessons
- Adding `post` to the shared `SessionLike` protocol rippled type errors into
  unrelated test fakes; a narrow `SearchSession` was introduced instead.
  Keep protocol additions scoped to the module that needs them.
- The shell has no active `.venv`; run tests/docs via
  `~/.virtualenvs/klea-3.13` explicitly. `make html` picks the system sphinx
  (lacks `sphinxcontrib.typer`); run the venv's `sphinx-build` directly.
- Env-file values load into pydantic settings, not `os.environ`, so they do
  not reach the bundled stdio subprocess; provider keys must be exported
  (documented in `install.rst`).

## Open Questions

## Notes
- The keyless providers are undocumented, anonymous, rate-limited hosted MCP
  endpoints; the pool + optional keys are the mitigation. `provider` is kept
  in results as cheap metadata that can support provenance phrasing.
- The transport deliberately does not use `fastmcp.Client` (the endpoints
  accept a direct `tools/call`; reuse the shared lifespan session; retry/UA
  are still required); rationale is recorded in `search/transport.py`.

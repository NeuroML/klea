## Decision

Gap. The Evaluator and the tool-round recorder always set `replan_reason` when
they escalate, but the Planner router also returns `need_replan` for a purely
structural condition: a failed step that blocks pending work (pending steps
remain while the dependency frontier is empty). On that path `replan_reason`
is empty, so the Planner prompt rendered no "Replan reason" section and the
model was asked to revise the plan with no hint about what went wrong.

Fix. The Planner now derives a short, deterministic replan reason itself. The
derived text is produced only when all of the following hold: `replan_reason`
is empty, `human_feedback` is empty, there are no `human_input` answers,
`validation_feedback` is empty, the plan status is `in_progress`, and pending
steps exist with an empty frontier. Two wording branches are used, chosen from
the retained plan: a failed step blocking pending work, or pending steps whose
dependencies are unresolved.

Precedence. The section is rendered as
`state.replan_reason or self._derived_replan_reason(...)`, so an explicit reason
from the Evaluator, the picker/binder or Triage is always rendered verbatim and
the derived text never overrides it. Any other feedback source suppresses the
derived text entirely, and a `needs_input` draft or guidance re-entry cannot
trigger it.

Scope. The change is prompt-only: no graph edge, no state field and no node
contract changed.

  `_get_prompt_variables` falls back to it.
- `agent_pkg/tests/test_planner.py` -- tests for each derived branch and for
  the suppression gates (explicit reason, human feedback, human input,
  validation feedback, non-`in_progress` plan).
- `CHANGELOG.md` -- Unreleased `### Fixed` entries for the derived replan
  reason and the failed-step replan routing.
- `devdocs/system/agent-node-contracts.md` -- Planner `replan_reason` prompt
  variable row extended with the derived fallback.
- `devdocs/system/prompt-conventions.md` -- rule added: a conditional prompt
  field may be deterministically synthesised when its source is empty but its
trigger is derivable from state, and an explicit value always wins.

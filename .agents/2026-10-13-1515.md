## Objective

token counts, improve path-permission rendering, and stop mangling user input.
Continuation of `.agents/2026-10-13-1015.md`.

## Completed

- **Token counts were wildly inflated** (a session showed 8.9 B input tokens
  while the provider billed ~$3.50).  Root-caused: the graph runs under
  `astream_events`, which forces chat models to stream, and LangChain's
  streamed `usage_metadata` merge (`add_ai_message_chunks`) sums input/total
  tokens across chunks for providers that report usage per chunk (HuggingFace
  Inference Providers, VLLM, ...).  Fixed by setting `disable_streaming=True`
  on every model in `LLMModel.build_config` (langchain#30429).  Verified with a
  fake model + `_should_stream` logic; the HF provider was down (503) so a
  live re-check was not possible.
- **Path-permission confirmations**: each decision now renders on its own line
  with the path in backticks (the `- ` bullet prefix was added by the
  maintainer).
- **User messages are rendered verbatim** (no Markdown decoration): literal
  underscores, `#`, lists, newlines and pasted code are preserved, with bare
  URLs kept clickable via a new `linkify_html` (HTML-escaped + safe anchors).
  Agent/system messages stay Markdown; tool messages stay MIME-based.
- Docs/tests updated; a backlog note added that the RAG summarise node still
  hardcodes the memory window.
- Added a backlog item to investigate `checkpoints.db` growth (see below).

## Errors and Lessons

- **Streaming usage bug (langchain#30429)**: `add_ai_message_chunks` sums
  `usage_metadata` across chunks; correct for OpenAI (usage once, final chunk),
  wrong for providers that emit usage per chunk.  Do not trust streamed
  `usage_metadata`; non-streaming is accurate.  Evidence: direct provider calls
  (small and ~1M-char prompts) returned correct usage; the same call via Klea
  with streaming inflated `44 -> 1540` input tokens.
- **Markdown mangles literal input** (`markdown2`): `my_file_name.py` ->
  `my<em>file</em>name.py`, `# x` -> `<h1>`, single newlines collapse.  User
  input must not be Markdown-rendered.
- **Stale test at HEAD**: the maintainer's `hitl` commit added the `- ` bullet
  prefix but left `test_stream_events.py` expecting the un-prefixed form, so
  the test failed at HEAD; aligned it to the committed format.
- `ChatOllama._generate` always streams internally (aggregates its own
  chunks), so it is a confound when testing `disable_streaming`.
